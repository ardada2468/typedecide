# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**, by reference. The full
text is at <https://www.contributor-covenant.org/version/2/1/code_of_conduct/> and
applies to every project space: issues, pull requests, discussions, reviews and commit
messages, and to anyone representing the project elsewhere.

In short: be respectful, assume good faith, criticise the code and the numbers rather
than the person, and do not harass anyone. Disagreement about methodology is welcome and
is most of the point of this repository; contempt is not.

## Reporting

Contact the maintainer through GitHub:

- for anything that can be discussed in the open, open an issue at
  <https://github.com/ardada2468/typedecide/issues>;
- for anything that should stay private, message the maintainer,
  [@ardada2468](https://github.com/ardada2468), or use GitHub's
  [report abuse](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
  tools, which reach GitHub staff directly.

Reports are handled confidentially. The maintainer will acknowledge a report, review it,
and respond with the action taken, following the enforcement guidelines of the
Contributor Covenant 2.1 (correction, warning, temporary ban, permanent ban). Someone
named in a report takes no part in handling it.
